# G5 tests: httpsec, webui, tunnel/cloudflare

Run (no Docker, no network, no Cloudflare):

    make -C <repo> lint test PKGS="./httpsec/... ./webui/... ./tunnel/..."

- `httpsec/httpsec_test.go`: ported from Family Hub `internal/httpx` (healthz, JSON 404, request log without secrets,
  recovery, body limit, a real server streaming SSE, busy port, the trusted-peer table) on `net/http` + `internal/testlog`;
  new: log levels and size, panic after the answer started, `Options` validation, `Chain` order, security headers, no-store.
- `webui/webui_test.go`: ported from `internal/web` with an `fstest.MapFS` build and stand-ins for the routes other packages
  own on the same mux (a path conflict would panic); new: option validation, the log line, `httpsec.New` in front.
  The literal `/assets/../index.html` is cleaned and redirected by `http.ServeMux` before the SPA; the SPA's own
  traversal guard is tested with `/assets/..%2findex.html`.
- `tunnel/cloudflare/cloudflare_test.go`: ported with the fake cloudflared `Runner`; new: `New` validation, the name prefix
  and the start hint.
- Time: nothing here reads the clock except durations in the request log.

Tests added in v0.2 are listed in [v0.2.md](v0.2.md).
