# G2 tests: store/sqlitestore

Run (no Docker, no network):

    make -C <repo> lint test PKGS=./store/sqlitestore/...

- `conformance_test.go`: `storetest.Run` on a fresh database file per case (temp dir, closed by `t.Cleanup`).
- `sqlitestore_test.go` (own tests):
  - `TestConformanceOnAFileWithApplicationTables`: the same suite on a store that also carries an application schema.
  - `TestOpenSettings`, `TestOpenRejectsBadOptions`: WAL, foreign keys, busy timeout, file 0600 / dir 0700, option checks.
  - `TestMigrations`, `TestMigrationIsAtomic`, `TestDatabaseFromTheFutureIsRefused`: fresh file, reopen (nothing re-applied,
    data kept), adding an application step, an older build refusing a newer database, a failing step leaving nothing.
  - `TestConnJoinsTransaction`: an application table written through `Conn(ctx)` commits and rolls back together with the
    gatekeeper's rows, nested `Tx` joins, a reader outside sees the last commit and does not wait, foreign keys are on.
  - `TestCascadeUsesTheDeleteTransaction`: a `store.Cascade` that deletes application rows through `Conn(ctx)` lands with the
    account delete and rolls back with it.
  - `TestWriteTransactionsAreSerialized`: 40 read-modify-write transactions lose no update and none fails with SQLITE_BUSY.
  - `TestTwoStoresOnOneFile`: two `Store`s (two pools) writing one file, the busy timeout covers it.
  - `TestWaitingForTheWriteLockHonoursTheContext`, `TestPanicInTxRollsBackAndReleasesTheLock`,
    `TestATransactionOfAnotherStoreIsNotJoined`, `TestErrorsAreWrapped`, `TestTimesComeBackInUTC`.
  - `TestAuditIDsSortByTime`: 300 appends under a frozen then back-stepping clock stay strictly ordered; cursor forms.
- Verified 2026-11-24: `go test -race -count=6` green; coverage 91 %; `golangci-lint` 0 issues.
- No sleeps: waits are channels and context deadlines (the one 50 ms deadline only bounds a call that must fail).

Tests added in v0.2 are listed in [v0.2.md](v0.2.md).
