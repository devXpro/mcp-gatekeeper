# G8 testing — the admin UI package

## Commands (repo root)

```sh
npm --prefix <repo> ci
npm --prefix <repo> run typecheck   # tsc -b: clean
npm --prefix <repo> run lint        # eslint --max-warnings 0: clean
npm --prefix <repo> test            # vitest: 8 files, 34 tests, green
```

## What the tests cover

Moved from Family Hub `web/src` (unchanged except the brand):
- `lib/api.test.ts`: the CSRF header on writes only (now the brand's header, asserted with a test brand
  `X-Gatekeeper-Test` so nothing Family Hub-specific is hard-wired), JSON bodies, error codes, 502 `module`/`reason`,
  `Retry-After`, offline detection, `no_session` listeners.
- `lib/consent.test.ts`, `lib/passkeys.test.ts`, `lib/links.test.ts` (`safeNext`; `normalizeRepo`/`repoURL` stay in
  Family Hub with the deployer).
- `i18n/i18n.test.ts`: RU and EN keys match, plural forms, interpolations, the copy rules, `detectLang`, `label`.
- `features/auth/stepup.test.tsx`: step-up passes through, retries once after the passkey, cancels quietly.

Not moved (they test code that stays in Family Hub): `lib/status.test.ts` (`stepStates`, `serviceLook`).

New:
- `setup.test.ts`: `configure()` keeps theme and language under the brand's storage prefix; an application's strings
  add keys and override the package's.
- `app/GatekeeperApp.test.tsx`: the whole app on a stubbed `fetch`: `/connect` built from the application's
  `resources` with the `Badge`, `BodyEnd`, `End` and `hintKey` slots, a disabled resource without its body, G7's
  connection rows (`resource`), the superadmin's extra tab; `/consent` reading G4's `resource`.

## Consumer smoke (outside the repo, not committed)

In `/tmp/g8work/consumer`: `npm pack` of the repo (what npm installs from a git dependency: `ui/src` without tests),
a Vite 8 + React + `@tailwindcss/vite` 4.3.5 app with Family Hub's strict tsconfig, `configure()` with Family Hub's
brand and `<GatekeeperApp>` with slots.
- `tsc --noEmit`: the package's sources type-check under the application's options.
- `vite build`: green; `qrcode` in its own lazy chunk; the CSS (37.9 kB) holds the package-only classes
  (`type-large-title`, `max-w-[720px]`, `pt-[calc(44px+env(safe-area-inset-top))]`, `fh-row`, tile colours) — the
  package stylesheet's own `@source` works from `node_modules`.
- Headless Chromium (npm Playwright 1.65.1, its own browser) against `vite preview` with `/api` routed to fixtures:
  `/login` renders, the passkey button is `rgb(0, 113, 227)` (`--accent-fill`), the POST carries `X-Family-Hub: 1`;
  `/connect` renders the sidebar, the card, the copy field, the assistant buttons and a connection exactly like
  Family Hub's `screenshots/20-connect-desktop-dark.webp`. No page errors (only the expected 401s of the signed-out
  run).

The pixel comparison of Family Hub before/after is G9's (its Playwright screenshots).
