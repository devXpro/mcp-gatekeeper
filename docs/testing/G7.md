# G7 testing — package people

Run: `make -C <repo> lint test PKGS=./people/...` (no Docker).

## Doubles

- `people/internal/memstore`: an in-memory `store.Store` with the adapters' semantics (ms precision, invite
  peek/consume errors, active-grant listing, account and person cascades, 24-hex growing audit ids, `Tx` in the
  context with rollback, a nested `Tx` joins). `Fail(method, err)` injects store failures.
- `harness_test.go`: `fakeSessions` is `core.Sessions` with the real rules (cookie → sha256 → session → viewer; CSRF
  header, Origin and Sec-Fetch-Site on writes → 403 forbidden; 401 no_session; 403 step_up_required);
  `fakeInviter` behaves like `auth.IssueInviteIn`; `fakeRevoker` revokes and audits `oauth.grant.revoke`;
  `fakeApp` is an application with every extension (modules as fields and summary counts, an eraser with injectable
  failures, legacy-key-like `lk_` connections with Family Hub's revoke rules).
