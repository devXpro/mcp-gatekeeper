## For the cards working in parallel

**Consent API JSON (G8, G9).** One change against Family Hub: in `GET /api/oauth/txn/{txn}` the key `module` is
now `resource`, with the same inner shape. Everything else (the other keys, approve/deny `{"redirect_url"}`, the
error codes and messages) is byte-for-byte Family Hub's.

```json
{
  "assistant": "chatgpt",
  "client_name": "ChatGPT",
  "client_kind": "cimd",
  "redirect_host": "chatgpt.com",
  "started_from": "assistant",
  "resource": {"id": "notes", "name": "Notes", "description": "…",
               "tools": [{"name": "…", "title": "…", "access": "read"}]},
  "account": {"id": "acc_…", "name": "…"},
  "already_granted": false
}
```

`tools` is always a list (`[]` when the resource has none).

type Options struct {
