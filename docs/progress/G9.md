## Changes to this repo (both generic, both tested)

- `people/respond.go`: an `APIError` with extra fields is written without a trailing newline, like
  `httpsec.WriteError` since 407e65c (Family Hub's 502 of a failed "delete everything" was `json.Marshal`'s bytes).
  `people/account_test.go` pins the bytes.
- `adminsock/client.go`: the client's requests name the application as their host when `CLI.App` can be one
  (`http://hub/v1/commands` for `App: "hub"`), else `http://admin`. Only the socket matters for the request, but the
  error of an unreachable socket quotes the URL, so `hub admin` prints what it always printed.
  `adminsock/adminsock_test.go` (`TestCLI`) pins both forms.

`make lint test integration` green after both.

## Notes for the next application (Homie)

- An application that keeps its own router mounts a package's routes with its own route table, each handing the
  request to a `ServeMux` holding the package's patterns (Family Hub: `internal/httpx.Mount` over Gin). The mux then
  redirects non-canonical paths (`..`, `//`) to the cleaned path before the package sees them.
- The UI package as a git dependency: an application with a manual `vendor` chunk group for `node_modules` must
  exclude `@devxpro/mcp-gatekeeper-ui`, or the package's lazy chunks (the QR code) become eager. The header comment
  of `ui/src/styles/index.css` shows `@source '../node_modules/…'`; `ui/README.md`'s `../../node_modules/…` is the
  path from an application's `src/styles/index.css`.
