## Notes for the orchestrator and G9

- **Go and node_modules.** `node_modules/flatted` ships Go code, so a local `npm install` at the root puts a Go
  package inside the module for `./...`. I wrote `node_modules/go.mod` (untracked, gitignored) as a local fence; `npm
  ci` deletes it. Change request: add `ignore ./node_modules` to `go.mod` (Go 1.25+; tested with go1.26 in a scratch
  module: `go list ./...` skips it).
- **Family Hub-only strings** were taken out of the package JSON: `admin.kept*`, `admin.module.*`, `admin.modules*`,
  `admin.system`, `admin.title`, `allowlist.*`, `deploy.*`, `job.*`, `module.*`, `secrets.*`, `setup.*`, `service.*`,
  `audit.action.module.*`, every `*legacy-key*` audit action, `stepup.action.{install,remove,rollback,secrets,start,
  stop,update,visibility,wipe}`, `connect.setup*`, `connect.enabled*`, `connect.empty.admin`, `connect.empty.install`,
  `connect.not_configured.member`. Family Hub can pass its current full `ru.json`/`en.json` as `strings` unchanged
  (the shared keys are identical).
