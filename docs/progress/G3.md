## The inviter G7 uses

`*auth.Auth` has exactly these methods, Family Hub's `people.Inviter` method set (the store is the gatekeeper's
`store.Store`; a transaction travels in ctx, so `IssueInviteIn` with the tx context joins it either way):

```go
func (a *Auth) IssueInvite(ctx context.Context, kind core.InviteKind, account core.AccountID, name string,
	by core.PersonID) (auth.IssuedInvite, error)
func (a *Auth) IssueInviteIn(ctx context.Context, st store.Store, kind core.InviteKind, account core.AccountID,
	name string, by core.PersonID) (auth.IssuedInvite, error)

type IssuedInvite struct {
	ID        string
	URL       string // <public URL>/join#t=<token>
	ExpiresAt time.Time
}

func NormalizeName(v string) (string, error) // errors wrap auth.ErrInvalidName
const MaxNameLen = 40
func (a *Auth) ClearSessionCookie(w http.ResponseWriter) // what DELETE /api/account sends after erasing the account
```

G7's `people.Inviter` returns `people.IssuedInvite` (same fields, same order), so the application wraps `*auth.Auth`
with `people.IssuedInvite(inv)` conversions.
