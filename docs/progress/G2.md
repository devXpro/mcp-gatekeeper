## Decisions

- **Table names are `gk_*`** so an application's tables (Homie's plugins) share the file without a clash. Times are
  INTEGER Unix ms (UTC); hashes and credential ids are BLOB; every table is STRICT.
- **No foreign keys between gatekeeper tables.** The conformance suite (like the Mongo adapter) writes passkeys, grants,
  tokens and invites that name people/accounts which do not exist, so such keys would fail it. Cascades are done in code
  inside one transaction (as in Family Hub's Mongo code). `PRAGMA foreign_keys=ON` still holds for the application's own
  tables, which may use real keys.
- **Writers are serialized in the process** by a one-slot channel lock taken before `BEGIN IMMEDIATE`. Why: SQLite has one
  writer; with only a busy timeout, 12+ goroutines racing for the lock depend on SQLite's unfair retry loop and a
  read-then-write transaction started DEFERRED can fail with SQLITE_BUSY at the upgrade. With the lock plus IMMEDIATE no
  in-process caller ever sees SQLITE_BUSY, the wait honours the caller's context, and the busy timeout (default 10 s) only
  matters for a second process on the file. Readers never take the lock: they use other pooled connections and WAL gives
  them the last commit.
- **Every writing store method runs in a write transaction** (joining the caller's when the context carries one), so the
  multi-step ones (`RevokeGrant`, `Consume`, deletes) are atomic on their own.
- **Atomic consume** = `UPDATE ... WHERE <live conditions> RETURNING` / `DELETE ... RETURNING`; no row → one more read in
  the same transaction decides `ErrNotFound` / `ErrExpired` / `ErrUsed` with the Mongo adapter's precedence. Expired code
  is deleted by the attempt and answered `ErrExpired` (the delete is committed).
- **Audit id**: 24 lower-case hex chars like an ObjectID (cursors look the same on both adapters). 8 bytes = a counter
  starting at `ms<<16` and raised by >= 1 per id (monotonic in a process even within a millisecond or when the clock steps
  back), 4 random bytes (two processes on one file). A cursor must be 24 hex chars (either case), otherwise an error.
- **`Conn` is a method** (`(*Store).Conn(ctx)`), because outside a transaction it must return this store's database.
  Contexts carry the transaction under a key that holds the `*Store`, so a transaction of one store is never joined by
  another.
- **Application migrations**: `Options.Migrations []Migration{Version, Name, SQL}` run after the gatekeeper's, each in its
  own immediate transaction, tracked as component `app` in `gk_schema_migrations`. A database ahead of the build is refused.
