## API notes for G8 and G9

**JSON renames against Family Hub (one):** `GET /api/account/connections` rows say `resource` where they said `module`
(same value: the resource id), like G4's consent rename. Everything else is byte-compatible; the fields Family Hub
adds (`modules` in `GET /api/account` and in each `GET /api/admin/accounts` row; `module`/`reason` in a failed
delete's error) now come from Family Hub's own extension and keep their names and shapes.

**The inviter.** `people.Inviter` has exactly Family Hub's method set: `IssueInvite(ctx, kind, account, name, by)` and
`IssueInviteIn(ctx, st store.Store, kind, account, name, by)`, returning `people.IssuedInvite{ID, URL, ExpiresAt}`.
`*auth.Auth` (G3) returns `auth.IssuedInvite` with the same fields in the same order, so G9 adapts with a plain
conversion `people.IssuedInvite(inv)` in a 10-line wrapper (people must not import auth).
