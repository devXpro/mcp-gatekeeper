# G1 — store conformance suite and MongoDB adapter: security notes

- **Secrets at rest.** The store keeps only what callers hand it: session ids, invite tokens, codes, tokens and
  client secrets arrive as sha256 (`core` types) and are stored as such. Nothing in `mongostore` hashes, logs or
  returns a secret in an error.
- **The connection string** carries credentials. It is never logged, and `redactURI` strips it from any driver error
  (`TestRedactURI`, `TestNewDoesNotLeakURI`, `TestOpenFails`, `TestMigrationsAreLogged`). The only log lines are
  "migration applied" with the version and name.
- **One-time use is atomic.** `Invites.Consume` and `OAuth.UseRefresh` are one `findOneAndUpdate` with the liveness
  conditions in the filter; `ConsumeCode` is one `findOneAndDelete`. Of 32 concurrent calls exactly one wins
  (conformance groups `*Concurrent`). A rotated refresh token reused reports `ErrUsed` even after it expired, so the
  caller can revoke the family.
- **One active grant per (person, client, resource)** is enforced by Family Hub's partial unique index
  (`revoked_at: {$type: "null"}`); active grants store `revoked_at: null` explicitly for it.
- **Deletes are complete and atomic.** An account or person delete removes passkeys, sessions, grants, tokens and codes
  in one transaction, and the application's `Cascade` runs in that same transaction: an error anywhere rolls everything
  back (DeleteCascades, CascadeHooks). Audit entries stay by design. The driver may re-run a transaction after a
  transient error, so a `Cascade` must keep its side effects inside the transaction (documented on `Store.Tx`).
- **Joining a transaction** happens only for a context whose session has a running transaction on the store's own
  client (`InTx` and the client check in `Tx`); a stale or foreign session starts a fresh transaction instead.
- **Audit cursors** are parsed as ObjectIDs before any query; a malformed cursor is an error, never a silent restart.
  Page sizes are capped at 1000.
- **TTL retention** is unchanged from Family Hub: sessions, codes and tokens at `expires_at`, invites 7 days after it,
  the audit 400 days after `at`.
- **Tests** run Mongo only in a throwaway container bound to 127.0.0.1 with a random port and a random name, removed
  after the run.
